# homelab-uptime

Внешняя проверка домашнего сервера через GitHub Actions: раз в 5 минут, тревога и восстановление — в ntfy.

Секреты репозитория:
- `CHECK_URLS` — проверяемые адреса, по одному на строку (сервер считается живым, если отвечает хоть один);
- `NTFY_TOPIC` — тема ntfy.sh.

Ручной запуск с тестовым уведомлением: Actions → uptime → Run workflow → «Отправить тестовое уведомление».
